# 🏛️ The Wealth Blueprint
**Master Your Money. Outsmart the Market.**

A high-conversion, premium landing page designed for selling advanced financial guides and courses. Built with a "Conversion-First" philosophy, focusing on trust, authority, and mathematical outcomes.

## 🚀 Tech Stack
- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** Vercel Optimized

## 🛠️ Architecture
The project follows a modular section-based architecture to allow for rapid A/B testing and high performance.

- `app/` $\rightarrow$ Core routing and page assembly.
- `components/sections/` $\rightarrow$ Conversion-focused funnel blocks (Hero, Social Proof, Pricing, etc.).
- `components/ui/` $\rightarrow$ Reusable premium UI primitives (Buttons, Cards).
- `constants/` $\rightarrow$ Centralized copywriting and pricing data for instant updates.
